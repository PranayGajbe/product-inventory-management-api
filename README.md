# Product Inventory and Stock Management API

A REST API for product catalog CRUD, stock-in/stock-out transactions and low-stock monitoring.

## Stack
Java 21, Spring Boot 3.5.6, Spring Web, Spring Data JPA, Hibernate, MySQL, Maven, Bean Validation, Swagger/OpenAPI.

## Run
1. Install JDK 21+, Maven 3.9+ and MySQL 8+.
2. Open this folder in IntelliJ IDEA.
3. Set `DB_USERNAME` and `DB_PASSWORD` environment variables, or edit `application.properties`.
4. Run `mvn spring-boot:run`.
5. Open `http://localhost:8080/swagger-ui.html`.
